## Limitations
This is a student prototype, not an official government portal. Grievance submissions are saved only in the demo database and are not delivered to government departments. Do not enter sensitive personal information. Proper admin authentication, rate limiting, retention policies, and a security review are required before public production use.

For Vercel deployment, follow the root `README.md` and initialize the database using `db/schema.sql`.
